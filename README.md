# Employee Record Table

A simple HTML project demonstrating the creation of a structured employee record table using HTML table elements. This project showcases the use of rows, columns, merged cells, and table formatting techniques.

## Features

* Employee Information Display
* Table Headers and Data Cells
* Column Merging using `colspan`
* Row Merging using `rowspan`
* Employee Job Details
* Work Experience Records
* Organized Tabular Layout

## Technologies Used

* HTML5

## Concepts Demonstrated

* HTML Tables (`<table>`)
* Table Rows (`<tr>`)
* Table Headers (`<th>`)
* Table Data Cells (`<td>`)
* Table Caption (`<caption>`)
* Column Spanning (`colspan`)
* Row Spanning (`rowspan`)
* Table Borders

## Table Structure

The table contains:

* Employee Names
* Job Roles
* Multiple Job Assignments
* Working Experience Information

## Purpose

This project was developed to practice HTML table creation and understand how tabular data can be organized effectively using various table attributes.

## Learning Outcomes

* Creating structured tables in HTML
* Using `colspan` and `rowspan`
* Organizing data in rows and columns
* Improving webpage content presentation
* Understanding table formatting concepts
